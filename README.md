# MyClipboard

一款常駐 Windows 托盤的剪貼簿歷史工具。你複製過的內容會被自動記錄，之後隨時找回、搜尋、收藏，一鍵貼回。

## 功能特色

- **自動記錄**：文字、富文本（RTF）、HTML、圖片，複製即存，無需手動操作
- **快捷呼出**：`Ctrl + Alt + X` 隨時顯示或隱藏主視窗
- **雙擊貼上**：雙擊任一記錄，自動貼回你剛才使用的視窗
- **搜尋**：輸入關鍵字即時篩選歷史
- **收藏**：常用內容標記為收藏，切到「我的收藏」只看它們；清空時收藏項不會被刪
- **右鍵操作**：收藏／取消收藏、編輯（文字記錄）、複製、刪除、清空未收藏、切換主題、關於
- **鍵盤操作**：`↑` `↓` 選擇、`PageUp` `PageDown` 翻頁、`Home` `End` 跳首尾、`Enter` 貼上、`Ctrl + C` 複製、`Esc` 隱藏
- **深色／淺色主題**：托盤選單或右鍵選單切換，設定會記住
- **托盤常駐**：按「—」或 `Esc` 只是隱藏介面，程式仍在背景記錄；從托盤選單可退出
- **純本機**：不連網、不上傳、無帳號

## 系統需求

- Windows 7 / 8 / 10 / 11
- .NET Framework 4.x（Windows 10/11 已內建，通常無需另裝）

## 開始使用

1. 執行 `MyClipboard.exe`，托盤會出現圖示（首次啟動會顯示使用提示）。
2. 如常複製文字或圖片，程式會自動記錄。
3. 按 `Ctrl + Alt + X` 開啟清單。
4. 雙擊記錄，或選中後按 `Enter`，內容會自動貼到剛才的視窗。
5. 按 `Esc`、再按一次快捷鍵，或按右上角「—」，即可隱藏介面。

## 資料存放與隱私

所有記錄只保存在本機：

| 位置 | 內容 |
| --- | --- |
| `C:\ProgramData\MyClipboard\history.dat` | 剪貼簿歷史（文字、圖片等） |
| `C:\ProgramData\MyClipboard\settings.dat` | 視窗位置、主題等設定 |

- 程式**不連網、不上傳、無雲端同步**。
- 資料**未加密**：密碼、驗證碼等敏感內容一旦複製也會被記錄。公用電腦或處理敏感資料時請留意。
- 歷史**沒有數量上限**，會持續累積；建議定期清理。

### 清除資料／移除程式

1. 從托盤選單選擇「退出」。
2. 刪除 `C:\ProgramData\MyClipboard` 資料夾，即可清空全部記錄與設定。
3. 如要移除程式，再刪除 `MyClipboard.exe` 本體即可。

## 常見問題

**快捷鍵沒反應？**
`Ctrl + Alt + X` 可能被其他程式佔用；關閉衝突程式後重新啟動 MyClipboard 即可。

**為什麼有些複製內容沒出現？**
檔案、特殊格式，或來自以管理員身分執行的程式的內容，可能無法記錄。

**圖片記錄很佔空間？**
圖片會以 PNG 原樣存入歷史檔，長期使用體積會變大，可定期用右鍵「清空」刪除未收藏的記錄。

**換電腦要帶走歷史？**
關閉程式後，把 `C:\ProgramData\MyClipboard\history.dat` 複製到新電腦的同一位置即可。

**介面跑到螢幕外？**
程式會自動把視窗限制在目前螢幕範圍內；若仍異常，刪除 `settings.dat` 讓位置重設。
